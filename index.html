구글 타임라인 데이터 받는 법

안드로이드

  1. 설정 → 위치 → 위치 서비스 → 타임라인
  2. 타임라인 데이터 내보내기 선택
  3. 저장된 Timeline.json을 여기에 올리기

아이폰

  1. Google 지도 앱 → 프로필 사진 → 타임라인
  2. 우측 상단 ⋯ → 위치 및 개인 정보 설정 → 타임라인 데이터 내보내기
  3. 저장된 location-history.json을 올리기

Google Takeout (예전 기록까지)

  1. takeout.google.com 접속
  2. “모두 선택 해제” 후 위치 기록(타임라인)만 체크 · 형식은 JSON
  3. 내려받은 .zip을 그대로 올리기 (압축을 풀지 않아도 됩니다)

아주 큰 Records.json(원시 위치 로그)은 브라우저가 감당하기 어려워 건너뜁니다. Semantic Location History 폴더의 월별 파일이나 기기에서 내보낸 Timeline.json을 쓰면 훨씬 빠르고 결과도 깔끔합니다.
